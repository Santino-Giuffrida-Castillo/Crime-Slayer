# Crime-Slayer

**Crime-Slayer** es un videojuego arcade inspirado en *Asteroids*, desarrollado en C++ utilizando la biblioteca gráfica raylib.

**Estado del proyecto:** Finalizado.

## Características

- Gameplay arcade inspirado en *Asteroids*.
- Movimiento espacial con inercia.
- Nave controlada mediante el mouse.
- Sistema de disparos y colisiones.
- Asteroides de distintos tamaños que se subdividen al ser destruidos.
- Sistema de puntaje y vidas.
- Menú principal, pausa y pantalla de créditos.
- Música y efectos de sonido.

## Controles

| Acción | Control |
|---|---|
| Apuntar la nave | Movimiento del mouse |
| Acelerar hacia la dirección apuntada | Clic derecho |
| Disparar | Clic izquierdo |
| Navegar por los menús | Mouse |
| Pausar el juego | Botón del medio del mouse |

## Tecnologías utilizadas

- **Lenguaje:** C++
- **Biblioteca gráfica:** raylib
- **Entorno de desarrollo:** Visual Studio
